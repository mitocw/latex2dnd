* v0.9.0, 2014-03-21 -- Initial release.
*     .1: add -C (can_reuse) flag
*     .2: improved box alignment and pixel position computation
*     .3: center labels in boxes; custom code when can_reuse=true
*     .4: add formula grading and gravity.tex example

* v1.2.0: add BEGIN_EXTRA_HEADER_TEX / END_EXTRA_HEADER_TEX multi-line preamble block to dndspec
*         fix pytest failure under Python 3.10 (except-clause variable scoping, PEP 3110)
*         add docs/dndspec.md with full dndspec documentation; update README.md to point to it

*         replace removed numpy.complex alias with builtin complex

*         add path package to install_requires
* v1.4.0: switch packaging from setup.py to pyproject.toml (PEP 517/518)
*         add test optional-dependencies (pytest, numpy, scipy, pyparsing)
*         add GitHub Actions CI workflow (tests against Python 3.10, 3.11, 3.12)
